# Smart Expense Tracker

A Flask-based web application for tracking daily expenses and managing personal finances.

## Features
- User Registration & Login
- Add, Edit, and Delete Expenses
- Expense Dashboard
- Expense Analytics
- SQLite Database Integration

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Run Project

```bash
pip install -r requirements.txt
python app.py
